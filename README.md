# TuvenanGYM 🏋️‍♂️

Kişisel antrenman, ağırlık ve vücut takibi sağlayan modern PWA (Progressive Web App).

## 🚀 Özellikler
- **Türkçe Varsayılan:** Açılışta doğrudan Türkçe arayüz (ayarlardan istenen dile geçilebilir).
- **Çevrimdışı Çalışma (PWA):** İnternet olmadan da antrenman ve egzersiz takibi.
- **Döngü & Sabit Hafta Planlama:** Esnek antrenman programları, RPE/RIR hesaplama.
- **Geçiş Anahtarı (Passkeys) & Güvenli Depolama:** İsteğe bağlı sunucu senkronizasyonu veya tamamen yerel kullanım.
- **Android & Mobil Uyumlu:** Capacitor destekli mobil altyapı.


## 🛠️ Yerel Geliştirme
```bash
npm install
npm run dev
```

Üretim derlemesi (Production build):
```bash
npm run build
```
